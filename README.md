#  clear_words
Бесплатная кросс-платформенная программа для очистки ключевых слов по стоп словам


## Реализованные интеграции и функционал:
Букварикс
Древовидная группировка  

## Установка
Есть 2 варианта для Windows
1) Скачать exe (в нем уже все библиотеки и питон) - [(Кликни СЮДА, чтобы скачать)](https://turbo-top.biz/soft/ClearWords.exe)
2) Запуск py файла (подходит для Windows/MacOS/Linux) откройте в терминале (в Windows cmd.exe) вбейте:  
```pip install pandas openpyxl```,  
далее просто запустить в терминале командой:  
```python путь_до_файла\clear_words.py```  
на MacOS чаще команда  
 ```python3 путь_до_файла\clear_words.py```
