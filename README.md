# Clear Words

**Бесплатная кроссплатформенная программа для сбора, очистки и группировки ключевых слов.**

Работа с семантическим ядром — это не только сбор запросов. Нужно находить мусорные слова, удалять дубли, быстро разбирать тысячи фраз и распределять полезные запросы по группам. **Clear Words** объединяет эти задачи в одном настольном приложении: от получения ключей до подготовки структурированного файла для дальнейшей работы.

Программа переписана на **Rust** с современным тёмным интерфейсом. Для работы с готовой сборкой не нужно отдельно устанавливать Python или его библиотеки.

## Возможности

### Сбор и импорт ключевых слов

- **Bukvarix** — получение ключевых фраз и частотностей через API, с бесплатным или собственным API-ключом.
- **Импорт CSV и Excel (XLSX)** — можно продолжить работу с уже собранной семантикой.
- **Пополнение текущей таблицы** — результаты парсинга добавляются к существующим данным.

### Очистка семантического ядра

- **Стоп-слова** — исключение ненужных фраз по словам; добавление стоп-слова прямо из ключевой фразы.
- **Массовая работа со стоп-словами** — импорт и экспорт списков в TXT, просмотр и удаление отдельных слов.
- **Удаление дублей** — как точных, так и неявных: с учётом перестановки слов и различий в пунктуации.
- **Поиск и сортировка** — поиск по нескольким словам одновременно, сортировка по ключевым фразам и частотностям.
- **Отмена изменений стоп-листа** — можно откатить последнее действие со стоп-словами.

### Умная группировка слов

Инструмент для быстрой массовой очистки, вдохновлённый анализом групп в SEO-программах:

- Автоматически находит часто встречающиеся слова и показывает, **в скольких фразах** они присутствуют.
- По желанию объединяет близкие словоформы, например «продвижение», «продвижения», «продвижению».
- Позволяет открыть любую группу и **просмотреть все совпавшие фразы** перед действием.
- Поддерживает выбор сразу нескольких групп, добавление найденных слов в стоп-лист или **массовое удаление совпадающих фраз** с подтверждением.
- Даёт возможность настроить минимальное число совпадений и область анализа.

*Умная группировка предназначена для анализа и очистки. Она не меняет пользовательские ветки автоматически.*

### Группировка и организация

- **Ветки и подветки** для распределения семантики по темам.
- Перенос отдельных фраз и выделенных наборов между ветками, в том числе перетаскиванием.
- Отбор фраз по группе и удобная работа с большими таблицами.
- Сохранение и открытие **проектов `.el`**, чтобы возвращаться к работе позже.

### Экспорт результатов

- Выгрузка в **CSV и Excel (XLSX)**.
- При экспорте в Excel каждая ветка становится отдельным листом; стоп-слова сохраняются на отдельном листе.

## Как это работает

1. **Соберите** фразы через Bukvarix или загрузите CSV/XLSX.
2. **Очистите** их вручную или с помощью умной группировки и стоп-слов.
3. **Разнесите** полезные запросы по веткам.
4. **Экспортируйте** результат или сохраните проект, чтобы продолжить позже.
